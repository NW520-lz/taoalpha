# 决策方法参考：道家文本与实践、矛盾分析

研究日期：2026-10-28
范围：核对用户指定的《德道经》文本与毛泽东《实践论》《矛盾论》的文本来源，并提出它们在 TaoAlpha 中作为决策纪律的可审阅用法。本文是资料研究，不构成交易信号、收益承诺或投资建议。

后续设计修订：同日讨论已将用途扩展到机会发现、条件识别、机制假设、验证与淘汰。最新开发契约以[交易研究与学习闭环规格](../STRATEGY_RESEARCH_SPEC.md)为准；本页保留来源、版本说明和原始行情样本，不将后续设计冒充原文结论。

## 结论摘要

三部文本可以用来设计“如何提出盈利假设、识别适用条件、承认不确定和检验判断”的流程，但不能单独推出币价方向，也不能证明策略有正收益。本资料提供来源差异和解释依据；从思想到交易规则的推演仍需研究与验证，原有授权、风控和准入规则继续适用。

本文把文本研究、市场事实、策略检验和执行结果分层。所有市场结论仍须引用带时间戳和单位的行情/事件数据；策略效能仍须由预先固定规则、含成本的历史验证和模拟闭环判断。哲学解释不计入回测优势、胜率或策略准入证据。

## 一、来源与版本核对

### 《德道经》 / 《道德经》

用户提供的 [Zacharia2/LaoZi-5000-Words《德道经.md》](https://github.com/Zacharia2/LaoZi-5000-Words/blob/main/%E5%BE%B7%E9%81%93%E7%BB%8F.md) 自述底本出处为文物出版社 1980 年版《马王堆汉墓帛书》，以帛书甲本为基础，同时合并其他版本，并用花括号标记增删、异文和注字。因此它是便于阅读和比对的整理文本，不能等同于帛书甲本的逐字照录，也不能把未加标记的现代标点、章节标题和解释当成出土原件本身。

[中国国家博物馆馆藏说明](https://www.chnmuseum.cn/zp/zpml/kgfjp/202108/t20210806_250982.shtml) 记载甲、乙本的形制、存字情况、篇序及与今本的差异：帛书是《德经》在前、《道经》在后，文字和章次也有不同。[马王堆帛书《老子》A、B 转写研究记录（Zenodo）](https://zenodo.org/records/12573936) 进一步说明两份帛书均有残缺，A 本残损更多；两本在词语、字形、篇段次序上也存在差别，且没有通行本那样系统的章号。该记录给出的断代属于研究假说，不应写成精确无争议的年代事实。[Paris Musées 的书目记录](https://parismuseescollections.paris.fr/en/node/786552) 则记录有马王堆帛书整理小组的 A、B 本释文出版物，可作为进一步核对的书目入口。

这意味着引用章节时应同时注明所据文本。例如，上述 GitHub 整理文本将“知足不辱，知止不殆，可以长久”列在其第七章；不要未经校对就把它编号成帛书、王弼本或所有通行本共有的同一章次。本文为避免混淆，优先用短语和用户提供文本的章节标题定位。

### 《实践论》与《矛盾论》

本次对读的中文全文页分别为 [《实践论》（1937 年 7 月）](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193707.htm) 和 [《矛盾论》（1937 年 8 月）](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193708.htm)。两页保留了题名、署期、正文和编者注，可用于文本核读；它们是网络转录，不是手稿影像或版本学定本。

尤其要留意，《实践论》页面注释记录了作者在 1951 年提出过局部修改意见；《矛盾论》页面将其定位为 1937 年文本。另一份《辩证法唯物论（讲授提纲）》转录页说明，所据翻印本包含《实践论》《矛盾论》的早期形态，且与后来《毛选》版本有较多出入。因此，若要做严格逐字研究，应先明确使用哪个版本。本文只抽取后来的通行全文页面所呈现的方法论要点，不声称完成了版本校勘。

## 三、TaoAlpha 的应用设计（我的推演，不是原文）

三者没有一个天然规定的交易软件工作流。下面是把上述阅读转译为产品流程的设计假设：

1. **先承认数据边界（《德道经》启发）**：研究摘要写明已知、未知、数据过期/缺失和冲突来源。若关键市场或账户事实不完整，结论允许为“等待 / 放弃”。“知止”可作为暂停与不过度交易的提醒，但不能直接生成仓位、止损点或阈值。
2. **针对特定币、产品和时间尺度列问题（《矛盾论》启发）**：独立研究角色先围绕本次同一证据快照识别影响判断的相反力量，区分主要假设与次要因素，并写明当前阶段、依据、反证及改变判断所需的数据。现货、永续合约和不同观察周期需分别描述。角色不得只以“多空票数”决定所谓主要矛盾。
3. **把判断写成可证伪计划（《实践论》启发）**：任何候选都要把观点写成可检验条件，包括入场依据、失效条件、退出规则、成本假设、数据时点与观察窗口；经预先登记的历史验证、样本外检查和 OKX 模拟闭环观察结果，再进入用户审阅。失败样本也要保存，不能事后改口或只选成功案例。
4. **把结果送回研究，但不自动改权限**：平仓与复盘后对照原始假设、交易所订单/成交、费用和滑点；标注预测偏差与不确定来源。复盘可提出策略变更草案，但须新建版本、重新验证并按项目既有的风险准入和逐卡确认流程处理。

### 建议的研究记录字段

- `source_snapshot_id`、数据来源、观测时间、交易所/产品/合约、单位、缺失或异常标志。
- `known_facts`、`unknowns`、`conflicts`：事实、未知项、来源冲突分别记录，不把模型推断写成行情事实。
- `primary_hypothesis`、`secondary_factors`、`counter_evidence`、`flip_conditions`：判断及其反证、失效/反转条件均引用证据 ID。
- 最新开发契约进一步区分 `principalConflict`、`dominantSide` 与 `mechanismHypothesis`；主要冲突、主导方面和机制假设不能混为一个字段，详见[开发规格](../STRATEGY_RESEARCH_SPEC.md)。本节其他字段为早期概念示意，不是已实现的接口名称。
- `strategy_version`、预注册条件、成本假设、样本外区间、模拟环境和评估结果；明确区分未验证、历史验证、模拟验证和真实执行。
- `decision`：等待、放弃、研究候选或生成待审交易卡；任何哲学用语都不能覆写确定性风控阻断。
- `review`：预测与实际的差异、手续费/滑点、订单及保护对账结果、改进提案和下一版本 ID。

## 四、不能从哲学文本推出的内容

- 哪个币会涨跌、在何价位入场/退出、应使用多少杠杆或资金。
- 某种叙事、K 线形态或所谓“天道周期”必然有效。
- Agent 共识、文本类比或主观“主要矛盾”具有胜率、统计显著性或盈利能力。
- 用户对某个研究结论的认可等于对订单的授权。

这些边界与 [项目不可破坏约束](../INVARIANTS.md) 中研究/执行隔离、逐卡批准、证据溯源及“哲学文本不是盈利证据”的规定一致；与 [验证方案](../EVALS.md) 的策略验证和模拟闭环要求一致。
