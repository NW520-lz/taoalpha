# Demo 账户会话基础

`src/account/demo-session.ts` 为后端配置的 demo 账户建立固定站点和账户身份绑定。它复用官方 Trade Kit 只读连接与 `demo-account.ts` 的字段归一；调用者不能通过研究 MCP 选择凭证、切换实盘或读取此内部会话。

第一次完整只读刷新后，本机 SQLite 保存一个随机的内部账户引用和账户身份摘要。相同站点与账户身份不能再登记到另一个范围，避免用两个范围分别计算预算。已绑定范围发现不同账户身份时，保存不可自动解除的冲突记录；即使原身份后来重新出现，冲突仍保持。此处还没有可信恢复入口。

账户权益和仓位只在进程内的后端快照中使用，快照不含原始账户 UID；研究 MCP 不暴露该快照。刷新开始前先持久化待处理状态，结束时只有仍为最新的请求才能发布结果；较早请求不能覆盖较新的失败或成功。读取器关闭前不发布快照。内部读取还核对最新状态、身份冲突及本连接的数据库可写性；过期同时使用墙上时钟和单调计时，防止时钟回拨延长有效期。刷新记录只保存状态与时间，不保存余额或仓位。数据库不可写时本会话阻断；只有成功记录待处理状态后才发起账户读取。如果只有某个连接在读取前不可写，它无法向其他仍可写的连接广播该失败，但也不会发起新的账户读取；其他连接的快照仍固定阻断新增风险，不能当作执行许可。重启后必须重新读取。多接口读取仍不构成交易所原子快照，后续提交前必须在受控事务中重新检查状态。

账户身份绑定只表示数据来自同一个 demo 账户，**不是**受管资产归属、资金流水、止损覆盖、风险配置或订单许可。所有结果保持 `reconciled: false`、`executionAuthorized: false` 和 `blockNewRisk: true`。自动追加保证金、合约估值与资金历史等缺项仍需分别核对；缺失能力不能按零或关闭处理。

测试使用合成账户、实际 SQLite 关闭/重开、双会话与故障替身。真实 demo 验证只输出连接和安全状态，不输出账户标识、金额或仓位。需要真实用户确认的账户基准与风险配置仍待可信入口接入。
