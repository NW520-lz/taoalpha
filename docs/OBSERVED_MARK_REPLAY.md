# 基于价格标记的研究回放基础

`replayObservedMarks` 是本地内部纯计算接口，不连接账户、交易所或交易执行。它接受研究者提供的有序价格标记、观察与可获知时间、显式数值规则和成本假设；数据既可以来自合成测试，也可以来自真实来源的研究数据。现阶段接口不能核验提交的价格、时间或来源，不把自报时间视为真实历史可获知时间。

规则版本 1 是一个仅供研究的例子：当前标记超过指定阈值时，在其可获知时间之后寻找下一个满足时间条件的标记，假设在那里入场，并按指定标记数持有后假设退出；每次只允许一个假设仓位。标记不是成交证据，也不自动等于已收盘 K 线。入场、退出标记仅在标记观察时刻与其自报可获知时刻相同时可作为假设价格；找不到时不捏造交易。任何标记的可获知时间缺失时不产生假设交易。输入必须单调且有界，拒绝不支持的产品和未知成本；当前只支持 USDT 现货多头，资金费标记为不适用。

数量使用基础币 `10^-8`，价格使用每基础币 USDT `10^-6`，手续费和价差/滑点影响以百万分率表示。每端手续费和价格影响各自作用于该端标记名义金额，各计一次；净额、毛额和成本均用 USDT `10^-20` 整数表示。手续费按标记名义额估算，不是影响价格后的实际手续费；真实深度、部分成交、延迟、费用档位和资金成本尚未建模。这是明确的粗略假设，不能代表实际成交或最大风险。

输出包含完整输入哈希、算法版本、假设交易和跳过原因，但始终为 `insufficient` 和 `executionAuthorized: false`。其输入哈希不证明来源真实，也不代表实验预登记或事前固定；输出没有“通过”状态。还需可信逐条可获知时间、已冻结且可执行的规则与数据/代码绑定、历史标的池、真实可解释成本与成交模型、样本外和评价标准，才能进入真实评价。当前 OKX 历史清单明确没有上述历史可获知时间，不能仅凭此内核宣称回测或策略验证完成。

`evaluateSyntheticFixture` 是遗留合成算术测试的辅助接口，结果标为 `unvalidated`；它同样不输出执行授权。`assessHistoricalReadiness` 列明当前缺项，不能代替未来的证据核验器。
