# TaoAlpha 研究 MCP

研究 MCP 使用当前 TypeScript 共享后端提供公开行情、证据和分阶段研究任务。它不读取 OKX 账户凭证，也不提供交易、确认或执行工具。宿主是否真的独立运行研究角色仍未核验，接口会保留 `hostVerified: false`。

需要 Node.js 24 或更高版本，并先在仓库内安装固定依赖。启动命令为：

```powershell
node "C:\path\to\taoalpha\src\mcp-main.ts"
```

使用 stdio 的 MCP 客户端可将 `node` 作为命令、上面的绝对脚本路径作为参数。这个路径需按实际克隆目录调整；脚本使用自身所在仓库定位默认策略，客户端当前目录不会改变策略位置。`TAOALPHA_DB` 可由本机启动环境配置绝对数据库路径；未设置时使用仓库下 `data/taoalpha.db`。数据库含研究证据和审计资料，应保留在本机，不提交到仓库。

接口列出八项研究操作：状态、公开行情扫描、证据包、证据、开始研究、获取任务、提交结构化报告或失败原因、读取结论。扫描和提交会写入本地研究数据库，但不会向交易所发送写请求。报告按既有角色和证据引用规则校验；请求不能指定服务端文件路径或更改行情端点。

此入口仍处于 M0 研究模式：候选草稿不可执行，策略未因模型报告而通过验证。账户对账、真人确认、风控预留和 demo 订单链路需要后续独立实现与验收。
