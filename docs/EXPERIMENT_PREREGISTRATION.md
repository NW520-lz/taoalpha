# 实验预登记内部内核

`createExperimentRegistry(db, now)` 提供 `register(input)` 和 `get(experimentId, version)`。它只在本机 SQLite 保存研究声明，不接 CLI、MCP、账户、凭证、网络或交易接口。首次登记的实验版本为 1；同一实验的后续版本必须递增 1，尝试 ID 全局唯一。同一个实验版本和尝试的完整内容相同可重放，任何变化须使用新的实验版本和尝试 ID。同一个策略 ID 和版本只能对应一份规则，规则变更须使用新的策略版本。

登记内容包括入场、退出和失效规则；数据及代码引用、版本及 SHA-256；不重叠且按时间排列的探索、验证和评价窗口；费用、价差、滑点、资金费及成交假设；预定指标、门槛、基准和方法。所有字段由调用方提供，无预设策略参数。文本是研究声明，不是经程序证明可执行的策略规则。记录含服务时钟的登记时间和整个正文的哈希；SQLite 事务和只追加触发器保护内容及策略版本。

数据及代码的哈希是调用方声明：此内核不读取、核验或保证历史清单、历史可获知时间、历史标的池、代码文件、数据覆盖或交易费用的真实性与完整性。每条记录始终标为 `unvalidated`、数据可用性 `unverified`、`executionAuthorized: false`。注册本身不能证明在结果出现前登记：目前没有评价器、可信时间戳或对外部结果的控制，也没有回测、结果、模拟或实盘准入功能。MR-06 和 MR-08 仅覆盖登记与状态边界的一部分，不能作为完整验收。SQLite 同一系统身份的恶意进程不在防护边界内。

无效输入、版本冲突和数据库不可用使用不同的固定错误类别；持久化失败回滚事务，存储记录损坏也按持久化不可用处理，不返回底层错误或输入文本。

局部表与现有历史清单互不替代；后续连接 `src/market/history.ts` 时必须核验所引用清单正文与哈希及历史缺口，不能仅凭这里的引用宣布数据可用。修改阈值、成本、窗口、数据或代码都要求新实验版本；不能覆盖旧记录。用户个人交易资料和凭证不得写入自由文本。
