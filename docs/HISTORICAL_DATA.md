# Historical data collection (H1)

This backend-only seam collects public OKX data; it does not provide a CLI, a backtest, an execution capability, or proof of strategy validity. No real OKX requests were made in the H1 tests. MR-04 is partially addressed; historical universe and publication-time evidence remain missing. MR-06 experiments and validation are not implemented here. D2 remains incomplete.

`collectHistory(client, options)` requires one USDT spot or USDT perpetual instrument, fixed resolution, integer Unix milliseconds `start`, `end`, `asOf`, UTC ISO `capturedAt`, and explicit `limit` (1–100) and `maxPages` (1–100). The window is **[start, end)** in candle-open or funding-event time; start and end must align to the selected bar. Resolutions are 1m, 5m, 15m, 1H, 4H and 1Dutc, aligned to Unix epoch in UTC. The window is limited to 100,000 candle intervals. The API cursor starts at `end + 1 ms` and advances via the oldest observed timestamp using `after`, which means older-than; all output is filtered to the requested window. `asOf` must be no later than local `capturedAt`.

Only nine-field candles with positive OHLC prices, high at least low, open and close within that range, nonnegative volumes, valid decimal strings, confirmed flag `1`, UTC alignment, and close time `open + resolution <= asOf` are retained. Decimal text is preserved, without floating-point financial calculations. Spot `vol` is base and `volCcy` quote; perpetual `vol` is contracts and `volCcy` base; `volCcyQuote` is quote. Returned range is the first and last accepted candle **open** time. Gaps include every missing expected open, malformed/unclosed rows, conflicting values, ordering and cursor issues, failed sources and page caps. A complete candle coverage flag applies only to that requested instrument/window and checks above, not correctness of exchange records or historical availability. Conflicting candles are removed; exact duplicates are flagged. Source responses and receipt times are preserved with body hashes; failed requests without a response retain an explicit error category.

Perpetual funding uses `fundingTime`, `fundingRate` (predicted) and `realizedRate` (realized public rate). The API documents up to three months and variable settlement intervals. No inferred cadence, complete funding coverage, zero fee or private account fee is claimed. Spot is `not_applicable`; perpetual coverage remains `unknown`, including empty and failed results. The public endpoint is the only funding source. No historical OI, time-aligned market structure, historical instrument universe, delisting history or actual publication timestamps are provided. A candle's close time is merely its earliest possible availability; it does not establish when the data was actually published. Survivorship and publication gaps are unconditional.

`saveHistory(db, manifest)` creates history-specific schema version 1 transactionally and stores a canonical JSON manifest with SHA-256-derived ID; public raw bodies, source references and normalized rows are included in the immutable payload. `getHistory(db, id)` initializes the history schema transactionally on a fresh database, returns null for an absent ID, and checks the stored hash. Exact replay is idempotent; an `attemptId` collision with different content fails. Optional predecessor and experiment references are labels only and do not establish experiment registration. Update, delete and replace triggers protect history records. This is an internal trusted backend seam: only pass manifests produced from approved public sources; it does not sanitize arbitrary caller-supplied manifest objects. No existing tables are modified. Future schema versions require a new explicit migration.
